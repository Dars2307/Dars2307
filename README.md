### What I work on

Most of what I build sits in the same place: the point where a person loses the thread, and a system could have kept it for them. That pulls me towards agent-native infrastructure, interfaces that explain themselves, and products where the hard part is modelling the problem rather than styling the page.

`agent-native tooling` `Model Context Protocol` `full-stack TypeScript` `edge and serverless` `interface design`
