### What I work on

Most of what I build sits in the same place: the point where a person loses the
thread, and a system could have kept it for them. That pulls me towards
agent-native infrastructure, interfaces that explain themselves, and products
where the hard part is modelling the problem rather than styling the page.

- Agent-native tooling and the Model Context Protocol
- Full-stack TypeScript, mostly Next.js and Node
- Edge and serverless platforms, Cloudflare Workers in particular
- Interface design that favours clarity over decoration

### Selected projects

#### ThreadLink

An authenticated routing layer between AI sessions. You stay in one primary
conversation and hand work to a linked execution agent, with the result returned
to the context it came from.

<sub>Next.js · TypeScript · Clerk · Supabase Postgres with RLS · MCP</sub><br>
<sub><b>Status:</b> public repository, alpha v0.1. Identity, session binding,
connection credentials and an MCP server are in place. Not production software.</sub>

#### Replex

Software discovery for developers and autonomous agents. Replex indexes public
repositories, classifies what each tool is actually for, checks compatibility
against a target stack, and scores agent readiness out of 100.

<sub>TypeScript · Express · Vite · MCP · PWA</sub><br>
<sub><b>Status:</b> public repository, prototype. Runs on in-memory storage, so
data resets when the server restarts. The Postgres schema is written but not yet
wired up.</sub>

#### Studle

A study app that turns recorded lectures into notes, summaries, quizzes and
flashcards organised by module. Capture runs in the browser with local recovery,
so a dropped connection does not cost you the recording.

<sub>Cloudflare Workers · D1 · R2 · Workers AI · Clerk</sub><br>
<sub><b>Status:</b> private repository, private beta at
<a href="https://studle.co.uk">studle.co.uk</a>.</sub>

#### InterviewGuru

An interview practice tool. It generates role-specific questions, rewrites your
answers back to you in STAR form, and keeps a coaching conversation alongside
your practice history.

<sub>React · TypeScript · Express · Drizzle ORM · OpenRouter</sub><br>
<sub><b>Status:</b> private repository, working prototype.</sub>
